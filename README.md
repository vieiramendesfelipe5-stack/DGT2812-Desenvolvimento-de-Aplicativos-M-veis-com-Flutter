# DGT2812-Desenvolvimento-de-Aplicativos-M-veis-com-Flutter
Este documento apresenta o desenvolvimento do Trabalho Prático da disciplina DGT2812 – Desenvolvimento de Aplicativos Móveis com Flutter. O projeto consiste na criação do aplicativo mobile/web para a agência de viagens fictícia Explore Mundo, projetado para oferecer uma interface responsiva, intuitiva e funcional aos clientes.
